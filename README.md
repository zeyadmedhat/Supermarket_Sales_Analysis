## 📌 Overview  
This project is an **interactive Streamlit dashboard** for analyzing supermarket sales data.  
It provides insights into:  
- 🏬 **Branch performance**  
- 💳 **Payment methods & revenue distribution**  
- 📈 **Sales trends over time**  
- 👥 **Customer demographics & behaviors**  

The goal is to make data-driven decisions to improve sales strategies.
